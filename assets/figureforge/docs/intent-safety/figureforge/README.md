# 智能体意图安全：从用户表达走到真实执行

用户表达的是目标，工具执行的是具体动作、对象和范围。智能体在补全这些细节时，可能把自己的推断或外部内容转化成执行依据。创新点一关注这段转换：让用户已经表达和确认的意图，持续约束最终发生的工具效果。

## 四张图的讲述顺序

1. **案例：一次项目交接。** 用户要求把三份定稿交给李明、整理旧版本、生成本地清单。两个同名联系人、未指定的访问级别，以及“整理”的多种解释，让执行细节存在缺口。智能体通过针对性澄清确认接收人和只读范围，完成三份报告的分享；旧文件操作保留待定，本地清单独立完成。
2. **问题：意图在工具提交前发生偏离。** 从自然语言目标到计划、工具参数和真实效果，每一次具体化都可能引入未经用户支持的假设。已知事实、用户确认的意图和未解决的授权条件需要分开记录，外部内容始终保留来源。
3. **抽象方法：用澄清维持意图与执行的一致。** 提取带证据的授权状态，建立“授权条件—任务义务”依赖图，在有限交互预算下选问题。用户回答经过校验后只更新对应范围，执行有充分依据的动作，再根据剩余义务继续决策。图中 R 与 P 共同解锁三个分享义务，C 对应旧版本操作。
4. **具体方法：学习意图语义和澄清价值。** Qwen3-8B + LoRA 共享解析初始请求和后续回答，提取字段、状态、范围与证据。两层 GraphSAGE + MLP 根据依赖图、候选问题和剩余预算估计澄清价值；多步规划产生的离线标签提供远期监督。固定工具效果契约和运行时校验把状态落实到具体执行。

本组图为方法设计示意。预算 1 / 2 的对比展示有效回答分支中的决策差异，数字来自该示例的依赖结构。
